# pong
Versión del clásico videojuego Pong utilizando Python y la biblioteca Pygame. El proyecto cuenta con dos jugadores, controles independientes mediante teclado (WASD y flechas), detección de colisiones, sistema de puntuación y efectos de sonido al anotar y termina a los 10 puntos. Tecnologías utilizadas: Python, Pygame. Daniel Delgado Quiñonez.
